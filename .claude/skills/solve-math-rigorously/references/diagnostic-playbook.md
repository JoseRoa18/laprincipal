# Diagnostic Playbook

Use this when the learner is making mistakes and the task is to identify the misconception, not only correct the final answer.

## Main Rule

Find the first invalid idea, not the last wrong number.

## Diagnostic Workflow

1. Reconstruct the learner's steps.
2. Mark the first place where the reasoning stops being valid.
3. Classify the error.
4. Use one or two discriminating follow-up checks.
5. Give the smallest correction that changes the idea.
6. End with one next problem that confirms the fix.

## Common Error Types

### Primary School

- operation-choice error
- place-value confusion
- regrouping error
- counting error
- fraction parts are not equal
- division interpreted as subtraction
- word problem language mismatch

### Later Math

- illegal algebraic transformation
- lost domain restriction
- sign error
- misuse of inverse operation
- treating examples as proof
- confusing local and global behavior

## Discriminating Checks

- ask for a picture or model
- ask for the reverse operation
- ask for one easier near-neighbor problem
- ask the learner to explain what each number means
- ask what the answer should roughly be before computing

## Reporting Format

When giving a diagnosis:

1. State the likely misconception in plain language.
2. Show the first invalid step.
3. Give the corrected idea with the smallest useful example.
4. Give one next-check problem or question.
