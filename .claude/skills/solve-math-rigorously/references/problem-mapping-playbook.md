# Problem Mapping Playbook

Use this before solving dense, ambiguous, or high-stakes math problems.

## Build The Map

Write down:

1. the target
2. the givens
3. the unknowns
4. the domain and constraints
5. the final form required

## Classify The Object

Decide whether the core task is:

- simplify or evaluate
- solve an equation or system
- solve an inequality
- optimize
- prove
- count
- model a word problem
- analyze a recurrence or sequence
- interpret a graph or geometry setup

Misclassification is one of the most common causes of bad solution paths.

## List Candidate Representations

Before solving, ask which representation is likely to help:

- factored form
- expanded form
- substitution
- coordinates
- vectors
- matrices
- table
- graph
- symmetry or invariant view
- probabilistic model

## Define Completion

Be explicit about what counts as done:

- all solutions, not only one
- exact answer, not only decimal
- proof, not only evidence
- optimal value and where it occurs
- interval, set, or region

## Quick Failure Checks

Before the first long derivation, ask:

- Are there excluded values?
- Could the claim be false?
- Is a smaller case enough to disprove it?
- Is there an easier equivalent form?
