# Lesson Playbook

Use this when the user wants a lesson, a mini-plan, or a structured teaching sequence rather than only worked examples.

## Core Lesson Shape

Prefer this order:

1. retrieval or warm-up
2. explicit model
3. guided practice
4. independent practice
5. exit ticket

## Planning Rules

- Keep the lesson goal narrow enough to teach in one sitting.
- Align the warm-up with prerequisites, not only the target skill.
- Make the teacher move explicit: what to say, show, or model first.
- Use the same representation across the model and the first guided problem.
- Let the exit ticket test the goal, not a different harder skill.

## Good Exit Tickets

A good exit ticket should:

- fit in one or two minutes
- check the exact success criteria
- reveal the most likely misconception quickly

## Primary-School Lessons

- use a manipulative or visual model before symbols
- keep the language stable
- prefer one worked example and a few strong reps over too many different formats

## Older Learners

- include one transfer item after the core pattern is secure
- name the method choice so the learner can reuse it later
