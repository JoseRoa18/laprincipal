# Mastery Playbook

Use this when the user wants a spiral review, spaced practice, or a mastery-oriented sequence across time.

## Main Principle

Do not confuse short-term success with mastery. Revisit skills after delay and in mixed context.

## Review Design

- include retrieval from previous topics
- keep one clear focus topic per day or session
- mix in one older topic for transfer
- end with a short mastery check or exit ticket

## Suggested Sequence

For a short review plan:

1. retrieval warm-up
2. focus practice
3. spiral review
4. exit ticket

## Mastery Signals

Look for:

- accurate work without heavy prompting
- correct method choice
- ability to explain the step, not only perform it
- success on a slightly changed or delayed problem

## When To Reteach

Reteach when errors cluster around the same idea. Do not only assign more repetitions of the same form.

## Tooling

Use `scripts/math_practice.py review-plan` to generate deterministic multi-day review materials.
