# Practice Playbook

Use this when the user wants drills, revision, a worksheet, homework, or a structured progression of problems.

## Practice Goals

Choose one primary goal:

- fluency
- misconception repair
- mixed review
- assessment
- challenge transfer

Do not mix all goals in a short worksheet.

## Good Sequence Shape

For a small worksheet, prefer:

1. one or two diagnostic or modeled items
2. several independent reps with the same structure
3. one transfer or challenge item
4. an answer key
5. a hint ladder for support

## Hint Ladder Rules

Hints should move from light to explicit:

1. point to the right representation
2. point to the next operation or transformation
3. show a partial setup
4. only then reveal the full method

Each hint should unlock one move, not the whole solution.

## Primary-School Practice

- keep the number range intentional
- use repeated visual models when the concept is new
- vary the surface story only after the structure is stable
- include one reverse-operation check

## Older Learners

- mix symbolic and verbal prompts
- include one item that forces transfer instead of repetition
- verify the answer key carefully

## Tooling

Use `scripts/math_practice.py` when you want a deterministic worksheet with answer keys and teacher notes.
Use `scripts/math_practice.py lesson` or `scripts/math_practice.py review-plan` when the user needs a structured sequence instead of a single worksheet.
