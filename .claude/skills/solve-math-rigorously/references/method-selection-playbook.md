# Method Selection Playbook

Choose a method because the structure points to it, not because it is familiar.

## Algebra

Use:

- factoring when terms suggest a product or root structure
- substitution when repeated composite expressions appear
- symmetry when swapping variables changes nothing
- logarithms or exponentials when multiplicative structure dominates

## Calculus

Use:

- derivative tests for local behavior and optimization
- substitution when the inside derivative is present or nearly present
- integration by parts when products involve one term that simplifies on differentiation
- dominant-term reasoning for limits and asymptotics

## Systems And Linear Algebra

Use:

- elimination when variables cancel cleanly
- substitution when one variable isolates cheaply
- matrix or vector form when the structure is genuinely linear
- eigen or determinant tools only when the problem is really about those objects

## Geometry And Trigonometry

Use:

- coordinates when distances, slopes, or loci are central
- vectors when direction and linear combinations matter
- trig identities when angle structure repeats
- synthetic reasoning only when it is actually shorter and clearer

## Probability, Counting, And Discrete Math

Use:

- complements when direct counting is messy
- conditioning when outcomes naturally branch
- invariants and extremal arguments when a process evolves over time
- recurrences or generating ideas when the structure repeats

## Method Pivot Triggers

Switch methods if:

- the algebra is growing but not simplifying
- a substitution removes one difficulty and introduces two more
- you keep re-deriving the same subexpression
- a small case suggests a pattern your current method is not using
