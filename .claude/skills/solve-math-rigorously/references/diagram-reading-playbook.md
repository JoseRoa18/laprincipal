# Diagram Reading Playbook

Use this when the photo includes a geometry diagram, graph, table, coordinate sketch, or labeled figure.

## Read The Marks First

List the explicit visual marks before inferring relationships:

- point labels
- side labels
- angle labels
- tick marks for equality
- right-angle boxes
- parallel markers
- axes and scales
- shaded regions
- arrows, directions, or vector marks

## Do Not Over-Infer

Do not assume from appearance alone:

- equal lengths
- right angles
- parallel lines
- midpoint locations
- graph intercepts or coordinates
- exact scale

A hand-drawn figure is evidence of intent, not proof of measurement.

## Build A Diagram Map

Create a compact map:

- objects present
- explicit given relations
- target quantity
- any useful coordinate or algebraic representation

## Good Pivots

- move to coordinates if the diagram is easier algebraically
- use a small labeled sketch in the explanation
- compare the visual claim with the written text to catch mismatches
